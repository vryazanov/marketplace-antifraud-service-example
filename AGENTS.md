# Antifraud Service

Читайте также общие инструкции лаборатории. Сохраняйте слои
presentation/infrastructure → application → domain; внутренние слои не зависят
от FastAPI, SQLAlchemy, httpx или Kafka. Python 3.13, uv, Ruff, pytest, Alembic.
Проверки и миграции — в README и Makefile. `make check` не исправляет файлы.

Jev вызывается только адаптером через LLM-шлюз; отдельный LMS_LLM_API_KEY
не равен ключу управления VLMS. Не выводите ключи, JWT или секреты БД.
.env игнорируется. Тесты не обращаются к платному API.
Меняя вопросы, обновите PROMPT_VERSION; меняя политику, убедитесь, что кэш
старых проверок не используется как новый результат.

Не подменяйте реальную оценку Jev результатами fake-классификатора. Датасет и
эксперименты хранятся в docs/antifraud мета-репозитория. Текущая версия — первый
этап: потребители решений в Ad/Auth/Search ещё не реализованы. Нельзя вызывать
физический DELETE Auth вместо требуемого soft delete.
